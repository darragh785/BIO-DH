# Darragh Hughes — Engineering Portfolio

Personal portfolio of Darragh Hughes, BEng (Hons) Intelligent Systems Engineering, MTU Cork, First Class Honours (76%).

## Website

Static HTML, CSS and JavaScript. No build step or API keys required. The site includes projects, coursework, engineering experience, MTU activities and personal photo galleries.

## Publishing

GitHub Pages can serve the `main` branch from `/(root)`. In repository Settings → Pages, choose Deploy from a branch, select `main` and `/(root)`, then save. No custom domain is required.

See UPLOAD_PROGRESS.md for the verified upload status. Two SkySpot video files remain to be uploaded into `assets/`; the website code, photos, CV and PetWatch video are present.
